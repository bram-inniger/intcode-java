# IntCode (Advent of Code 2019)

Repository to store IntCode solutions for [Advent of Code](https://adventofcode.com/2019)

## About

Find inputs under ["inputs"](src/main/resources/inputs).
The solutions (both parts, including tests) can be found under ["problems"](./src/test/java/be/inniger/problems).

## How to run

    $ git clone git@github.com:bram-inniger/intcode-java.git
    $ cd intcode-java
    $ ./gradlew clean build
